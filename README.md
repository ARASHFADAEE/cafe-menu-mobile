# استیلا | منوی کافه و دیسکو + پنل ادمین

اپ Next.js برای منوی موبایل کافه استیلا با تم بنفش لوکس، دیسکو، تماس/لوکیشن و پنل مدیریت.

## اجرا

```bash
npm install
npm run dev
```

- منوی عمومی: [http://localhost:3000](http://localhost:3000)
- پنل ادمین: [http://localhost:3000/admin](http://localhost:3000/admin)
- رمز ادمین پیش‌فرض: `estila2024`

## امکانات ادمین
- مدیریت محصولات (افزودن / ویرایش / حذف / فعال‌سازی)
- مدیریت دسته‌بندی‌ها
- تغییر بنر هیرو (عنوان، متن، تصویر، بج دیسکو)
- ویرایش اطلاعات کافه (آدرس، تلفن، ساعات، نقشه، اینستاگرام)

داده‌ها در `localStorage` مرورگر ذخیره می‌شوند تا بدون دیتابیس هم قابل دمو باشد.

## بیلد

```bash
npm run build
npm start
```
